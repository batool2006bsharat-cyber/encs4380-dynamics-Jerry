Dynamic Characteristics Toolkit

ENCS4380 Interfacing Techniques · Homework 1

A sensor never reports the present. It reports the past, smoothed. These four interactive modules show how τ, ζ and ωn decide how far behind a sensor is, and then ask you to read those parameters off a curve you have never seen.

Modules

MODULE 1

First-order time response

A thermometer: τẏ + y = Kx. Step and ramp inputs, the 63.2% and 95% points, ramp lag and the log error-fraction plot.

Open module → MODULE 2

First-order frequency response

Input and output sines on one plot, amplitude ratio and phase lag, the Bode plot with its cutoff at ω = 1/τ, and a dynamic-error calculator.

Open module → MODULE 3

Second-order response

An accelerometer or spring: under, critical and overdamped steps, metrics read off the curve, poles, state-space model and phase plane.

Open module → MODULE 4

Guess the sensor

A hidden random sensor produces a noisy response. Estimate τ, or ζ and ωn, then reveal the truth and score your guess.
