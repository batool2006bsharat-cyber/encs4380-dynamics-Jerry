Where does the critical τs come from?

With the sensor in the loop, the closed-loop characteristic equation is

τ·τs·s³ + (τ + τs + K·Kd)·s² + (1 + K·Kp)·s + K·Ki = 0

Routh–Hurwitz says this third-order loop is stable only while

(τ + τs + K·Kd)(1 + K·Kp) > τ·τs·K·Ki

Solving for τs gives the largest sensor lag the loop can tolerate:

τs,crit = (τ + K·Kd)(1 + K·Kp) / (τ·K·Ki − (1 + K·Kp))

At τs,crit the loop oscillates at ω² = K·Ki / (τ + τs,crit + K·Kd). Without Ki (or with τ·K·Ki ≤ 1 + K·Kp) there is no critical value, and the sensor only reduces damping. This is a linear result: in the simulation the ±20 actuator limit keeps an unstable loop bounded, so it shows up as a sustained oscillation instead of growing forever.

*Last-sample error estimates steady-state error only when the output has converged. Unsettled trajectories are marked accordingly.
